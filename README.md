# 🐍 Python Projects

A curated collection of beginner-level Python projects created to practice programming fundamentals, algorithmic logic, and problem-solving skills.

---

## 🎯 Objectives
* Strengthen core Python syntax and data structures.
* Develop logical thinking through hands-on coding exercises.
* Build a solid foundation for more complex software development.

## 🛠️ Technologies & Concepts Covered
* **Language:** Python 3.x
* **Fundamentals:** Variables, data types, operators, and string manipulation.
* **Control Flow:** `if/else` statements, `for` and `while` loops.
* **Data Structures:** Lists, tuples, sets, and dictionaries.
* **Modularization:** Functions, modules, and basic error handling (`try/except`).

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/arthursoaresabiviolo-ux/python-projects](https://github.com/arthursoaresabiviolo-ux/python-projects)
   ```

2. **Navigate to the project folder:**
   ```bash
   cd python-projects
   ```

3. **Run a script:**
   ```bash
   python folder_name/script_name.py
   ```

# 🐍 Projetos em Python

Uma coleção selecionada de projetos em Python de nível iniciante, criados para praticar fundamentos de programação, lógica algorítmica e resolução de problemas.

---

## 🎯 Objetivos
* Fortalecer a sintaxe básica e as estruturas de dados do Python.
* Desenvolver o pensamento lógico por meio de exercícios práticos de programação.
* Construir uma base sólida para o desenvolvimento de softwares mais complexos.

## 🛠️ Tecnologias e Conceitos Abordados
* **Linguagem:** Python 3.x
* **Fundamentos:** Variáveis, tipos de dados, operadores e manipulação de strings.
* **Controle de Fluxo:** Estruturas condicionais (`if/else`) e laços de repetição (`for` e `while`).
* **Estruturas de Dados:** Listas, tuplas, conjuntos (*sets*) e dicionários.
* **Modularização:** Funções, módulos e tratamento básico de erros (`try/except`).

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/arthursoaresabiviolo-ux/python-projects](https://github.com/arthursoaresabiviolo-ux/python-projects)
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd python-projects
   ```

3. **Execute um script:**
   ```bash
   python nome_da_pasta/nome_do_script.py
   ```
